# Ferramentas de Desenvolvimento Web

> **Área:** Web, Mobile & IHC · **Tecnologias:** HTML, CSS, JavaScript e PHP · **Ano:** 2023

## 📖 Sobre

Atividades práticas e projeto desenvolvidos na disciplina de **Ferramentas de Desenvolvimento Web**, cobrindo estruturação semântica em HTML, estilização com CSS, interatividade no navegador com JavaScript, formulários e backend com PHP.

## 📂 Conteúdo da Pasta

- `HTML + CSS/` — exercícios de marcação e estilização.
- `Comportamento com JavaScript/` — manipulação do DOM e eventos em JavaScript.
- `form/` — páginas e validação de formulários web.
- `PHP/` — scripts server-side em PHP.
- `Trabalho/` — projeto prático da disciplina.

## 🚀 Como Executar

- Para páginas estáticas (`HTML + CSS`, `JavaScript`, `form`), abra o arquivo `.html` diretamente no navegador.
- Para os arquivos em `PHP/`, execute o servidor embutido do PHP:

```bash
cd PHP
php -S localhost:8000
```
