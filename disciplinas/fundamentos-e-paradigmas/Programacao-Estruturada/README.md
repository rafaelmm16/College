# Programação Estruturada

> **Área:** Fundamentos & Paradigmas · **Linguagem:** C · **Ano:** 2020

## 📖 Sobre

Materiais, exercícios e exemplos desenvolvidos durante a disciplina de **Programação Estruturada** em linguagem **C**, cobrindo lógica de programação, manipulação de strings, ponteiros, funções e estruturas de controle.

## 📂 Conteúdo da Pasta

- `Exemplos/` — códigos de exemplo e testes em C.
- `Programação Estruturada/` — exercícios e atividades da disciplina.
- `biblioteca-string-commands.txt` — anotações sobre funções da biblioteca `<string.h>`.
- `centraliza-string.c` — exemplo de formatação e centralização de strings.
- `grande-conteudo-em-c.c` — compilado de exercícios e práticas em C.

## 🚀 Como Executar

Requer um compilador C (como `gcc` ou `clang`):

```bash
gcc arquivo.c -o programa
./programa
```
