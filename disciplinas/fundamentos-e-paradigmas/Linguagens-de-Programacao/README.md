# Linguagens de Programação

> **Área:** Fundamentos & Paradigmas · **Linguagens:** C, C++ e Java · **Ano:** 2023

## 📖 Sobre

Materiais teóricos, avaliações, códigos comparativos e trabalhos práticos da disciplina de **Linguagens de Programação**, explorando gerenciamento de variáveis, categorias de vetores, tipagem, escopo e comparação entre linguagens.

## 📂 Conteúdo da Pasta

- `Avaliação II/` — arquivos da avaliação prática da disciplina.
- `Gerenciamento de variáveis/` — experimentos sobre escopo, tempo de vida e armazenamento de variáveis.
- `Trabalho sobre Logs do Apache/` — análise e processamento de arquivos de log.
- `Trabalho sobre Mapas/` — estudo prático com estruturas de mapeamento.
- `Trabalhos Antigos/` — acervo complementar de atividades.
- `Mapeamentos - Categoria de Vetores.*` e `Register em C.c` — comparativos em C, C++ e Java.
- `Apresentacao_LP_Parte01..04.pdf` e `Analise *.pdf` — slides e análises teóricas da disciplina.

## 🚀 Como Executar

Para os exemplos em C/C++ ou Java:

```bash
# C
gcc "Register em C.c" -o programa && ./programa

# Java
javac "Mapeamentos - Categoria de Vetores (1).java"
```
