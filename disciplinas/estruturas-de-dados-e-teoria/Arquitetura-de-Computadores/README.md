# Arquitetura de Computadores

> **Área:** Estruturas de Dados & Teoria · **Linguagem:** Assembly (MIPS) · **Ano:** 2023

## 📖 Sobre

Atividades práticas da disciplina de **Arquitetura de Computadores**, explorando organização de memória, registradores, conjunto de instruções e programação em baixo nível em **Assembly MIPS** com o simulador **MARS**.

## 📂 Conteúdo da Pasta

- `Aula 11 - Códigos/` — códigos de exemplo e exercícios em Assembly.
- `ED 11.asm` — código-fonte Assembly MIPS.
- `Mars4_5.jar` — simulador MIPS MARS 4.5.

## 🚀 Como Executar

Requer **Java (JRE/JDK)** instalado para abrir o simulador MARS:

```bash
java -jar Mars4_5.jar
```

Em seguida, abra os arquivos `.asm` dentro do MARS para montar (*Assemble*) e executar.
