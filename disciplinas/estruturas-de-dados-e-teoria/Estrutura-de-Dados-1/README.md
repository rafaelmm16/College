# Estrutura de Dados I

> **Área:** Estruturas de Dados & Teoria · **Linguagem:** C · **Ano:** 2021

## 📖 Sobre

Exercícios de programação, mini-exercícios e listas desenvolvidas na disciplina de **Estrutura de Dados I** em **C**, trabalhando alocação dinâmica de memória, ponteiros, listas, pilhas, filas e algoritmos de busca.

## 📂 Conteúdo da Pasta

- `EP1/`, `EP2/`, `EP3/` — Exercícios de Programação (EPs).
- `mEP1/`, `mEP2/`, `mEP3/` — Mini Exercícios de Programação (mEPs).
- `Lista01/` a `Lista05/` — listas de exercícios da disciplina.
- `Anotações.txt` — resumos e notas de aula.

## 🚀 Como Executar

Requer um compilador C (`gcc` ou `clang`):

```bash
gcc arquivo.c -o programa
./programa
```
