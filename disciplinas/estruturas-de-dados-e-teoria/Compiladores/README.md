# Compiladores

> **Área:** Estruturas de Dados & Teoria · **Linguagens:** C++ e Java · **Ano:** 2023

## 📖 Sobre

Atividades e implementações realizadas durante a disciplina de **Compiladores**, incluindo construção de compiladores simples, análise léxica/sintática e manipulação de expressões.

## 📂 Conteúdo da Pasta

- `main.cpp` e `Calculadora-Com-XML.cpp` — implementações em C++.
- `compiladorSimples/` e `SimpleCompiler-master/` — projetos de compiladores simples.
- `Compilador Simples em Java/` — implementação de compilador simples em Java.

## 🚀 Como Executar

Para os códigos em C++:

```bash
g++ main.cpp -o compilador
./compilador
```
