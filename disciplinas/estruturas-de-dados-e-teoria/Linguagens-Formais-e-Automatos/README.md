# Linguagens Formais e Autômatos

> **Área:** Estruturas de Dados & Teoria · **Linguagem:** Python · **Ano:** 2023

## 📖 Sobre

Trabalho e implementações desenvolvidas para a disciplina de **Linguagens Formais e Autômatos (LFA)**, com foco na construção de analisadores **léxico** e **sintático** em Python.

## 📂 Conteúdo da Pasta

- `Analisador Lexico.py` — implementação do analisador léxico.
- `Analisador Sintatico.py` — implementação do analisador sintático.
- `file.txt` — arquivo de entrada para testes.
- `Trabalho - Analisadores léxico e sintático.pdf` — enunciado/documentação do trabalho.

## 🚀 Como Executar

Requer [Python 3](https://www.python.org/downloads/) instalado:

```bash
python "Analisador Lexico.py"
python "Analisador Sintatico.py"
```
